# Computer use

**Acting through a computer interface by observing the screen and issuing input.**

## In plain terms

Anthropic describes computer use in terms of screenshots and actions such as clicking and typing. This gives an agent a route through graphical interfaces rather than only through structured service APIs.

Imagine a course agent opening a syllabus in a browser and filling a form. The visible screen state and the submitted result are evidence to inspect. Mini-claw does not include computer use: its one-tool design is a smaller comparison point.

# Subagent

**A separate agent given a narrower part of a larger task.**

## In plain terms

Claude Code subagents can work with separate context and configured tools. Delegation changes how information and work are divided; it does not remove the need to inspect results.

Invented student example: one subagent checks quotations while the main agent revises structure. A useful report identifies which passages were checked and which remain uncertain, rather than simply announcing that checking is complete.

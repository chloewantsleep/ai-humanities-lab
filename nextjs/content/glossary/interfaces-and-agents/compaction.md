# Compaction

**Replacing some earlier context with a shorter account to make room for continued work.**

## In plain terms

Claude Code can summarize a long conversation as its context fills. A summary preserves selected information, so it should not be treated as a verbatim transcript.

Imagine a student’s exact wording for a thesis disappearing into “the student wants a stronger thesis.” Before a later edit, the student can ask the agent to reread the source document.

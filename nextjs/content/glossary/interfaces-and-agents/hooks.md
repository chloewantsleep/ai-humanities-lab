# Hooks

**Programs triggered at specified points in an agent application’s lifecycle.**

## In plain terms

Claude Code hooks run at lifecycle events, such as around tool use. A hook is executable automation, whereas a skill mainly supplies instructions for the agent to interpret.

An invented classroom setup could use a hook to record tool events for review. Inspect the program and the event that invokes it; the word “hook” alone says little about what it will do.

# Workflow

**A sequence of steps whose path is largely specified in advance.**

## In plain terms

A workflow can call a language model while leaving the overall order to code. Anthropic contrasts that pattern with an agent choosing its own next steps. Both can appear inside one application.

An invented course workflow might always extract a thesis, list evidence, then ask a discussion question. An agent would have more discretion about which step to take next.

# Voice assistant

**An assistant interface that accepts spoken requests and can answer with synthesized speech.**

## In plain terms

Speech recognition turns an utterance into input; software interprets the request, may call a tool, and can synthesize a spoken response. These are separable parts. A system that reads text aloud is not necessarily able to listen, and a speaking voice does not establish understanding.

## In the readings

For a course comparison, use [voice](../persona-and-dialogue/voice.md) to distinguish audible qualities from the recognizable style of a textual speaker. [Dr. Sbaitso](../chatbots/dr-sbaitso.md) is a useful comparison for speech output around a typed exchange.

## Try it

Read a reply from [ELIZA](/eliza) aloud and then inspect its rule. This proposed exercise separates a vocal performance from the procedure that selected the words; the experiment itself uses text.

# Plugins

**Installable packages that extend an application’s capabilities.**

## In plain terms

In Claude Code, plugins can bundle skills, agents, hooks, and MCP servers. A plugin is the package; a tool is an operation the agent may call. Product uses of the word vary.

For a student, inspect what a proposed plugin adds before installing it: instructions and executable integrations have different consequences. A product banner calling something a plugin does not establish a shared technical format.

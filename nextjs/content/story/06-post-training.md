# Training an assistant

Researchers developed several ways to make a model answer instructions. A prompt can include sample conversations for the model to continue. Further training can teach it to imitate example answers and favor responses that reviewers rank highly. These methods shape its behavior before a user starts a chat. [Read the InstructGPT paper](https://arxiv.org/abs/2203.02155).

ChatGPT launched in November 2022 with a conversational interface. The interface keeps a message history, separates user and assistant turns, and lets the user ask follow-up questions. [Read the launch announcement](https://openai.com/index/chatgpt/).

# Timeline content

The main page contains six sections: ELIZA, GPT-2, training an assistant, the 2023 builder, reasoning models, and tools and agents. The Poetry Gem builder appears after the 2023 section. The later sections follow it.

Each Markdown file has frontmatter for its title, date, and description. A `panel` code block defines a demonstration or figure. The text after that block appears beside it. ELIZA uses `demo: eliza`; GPT-2 uses `demo: spiral`.

Files marked `hidden: true` retain material from the longer draft. They are excluded from the main timeline. The `samples/` folder preserves the recorded GPT-2 outputs.

The text uses short sentences, direct instructions, and literal headings, following principles described in the [ASD-STE100 FAQ](https://www.asd-ste100.org/STE_faq.html). It has not been certified against the full specification.

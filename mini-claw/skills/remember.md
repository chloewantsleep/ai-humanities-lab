# Remember

Memory is the only thing that survives between runs: each run starts with no conversation, only `memory.md`.

1. Decide whether it is worth keeping: a fact about the user, their project, or a standing preference. Not a passing remark, not something already in memory, and never a password, a key, or something private about another person.
2. Append one line to `memory.md` with the file tool: action `append`, path `memory.md`, text `- YYYY-MM-DD: <the fact, in one short sentence>`, using today's date from your instructions.
3. Tell the user in one sentence what you saved.

# Commonplace book

A commonplace book is a reader's notebook of passages copied out under headings. This one lives at `notes/commonplace.md`.

1. To show it, read `notes/commonplace.md`. If it doesn't exist yet, say so.
2. To add a passage, append to `notes/commonplace.md`:
   - a heading line, `## <a theme in a word or two>`
   - the passage as a `>` quotation, exactly as the user gave it
   - a line `— <author>, <work>, <page or section>`. If the user didn't say where it comes from, write `— source not given`. Never guess a source.
   - if the user commented on it, a line `Comment: <their comment>`. Don't add your own reading unless they ask for one.
3. Tell the user the heading you filed it under.
